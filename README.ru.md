# Codex State Kit

[简体中文](README.md) | Русский

Локальное настольное приложение для Codex: проксирование запросов, управление
аккаунтами ChatGPT, исходящими маршрутами и виртуальными устройствами, история
использования и оценка стоимости запросов.

Приложение написано на Tauri, Rust и React. Результат зависит от аккаунта, сети
и сервиса на стороне сервера. Kit не гарантирует устранение перегрузок или
повышение возможностей модели.

## Язык интерфейса

Выберите **Русский** в списке языков в заголовке окна. Переключение между русским
и китайским происходит без перезапуска. Настройка сохраняется локально; меню
трея синхронизируется с выбранным языком. По умолчанию сохранён китайский язык
исходного проекта.

Язык интерфейса не меняет локаль виртуального устройства, параметры запросов
или аккаунта. Имена узлов, адреса, идентификаторы моделей и исходные диагностические
сообщения сервера не переводятся. Подробности для разработчиков —
в [документации по локализации](docs/localization.md).

## Начало работы

1. Запустите Kit. В разделе **Подключение Codex** проверьте рабочий каталог:
   он должен совпадать с каталогом настроек клиента Codex, обычно `~/.codex`.
   Одновременно может работать только один экземпляр Kit.
2. Нажмите **Добавить аккаунт** и войдите через браузер, код авторизации,
   Refresh Token или Access Token. Для входа используется текущий исходящий маршрут;
   новый аккаунт будет привязан к нему.
3. В разделе **Исходящая сеть** настройте ручной прокси либо подписку Clash/Mihomo.
4. Дождитесь статуса **Подключено** и перезапустите клиент Codex, чтобы он подхватил
   локальный маршрут.
5. Оставляйте Kit запущенным во время работы. После штатного выхода из Kit
   перезапустите Codex: исходный аккаунт и локальная конфигурация будут восстановлены.

## Возможности

- Переключение сохранённых аккаунтов из окна или трея без перезапуска Codex.
- Отдельные виртуальные устройства и исходящие маршруты для разных аккаунтов.
- Ручные прокси `socks5`, `socks5h`, `http`, сессии `{session}` и узлы подписок.
- История моделей, транспорта, времени до первого токена, длительности, токенов и стоимости.
- Сигналы понижения модели и возможного снижения качества по признакам официального клиента.
- Синхронизация каталога цен с sub2api и учёт кешированных токенов и тарифов.
- Принудительный выбор модели для пересылаемых запросов.
- Проверка обновлений, проверка подписи пакетов и установка с подтверждением.

```text
Клиент Codex → локальный прокси Kit → исходящий маршрут → сервер Codex
```

В релизной сборке локальный прокси по умолчанию слушает `127.0.0.1:8787`.

## Разработка и проверки

Нужны Node.js, версия pnpm из `package.json`, Rust и системные зависимости Tauri.
Используйте Rust, совместимый с зафиксированными зависимостями в `Cargo.lock`.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm dev:renderer
```

Браузерный режим использует демонстрационные данные: он не изменяет реальную
конфигурацию Codex и не запускает ядро подписки. Для настольного режима используйте
`corepack pnpm dev` и отдельный тестовый каталог Codex, поскольку этот режим
выполняет реальные операции.

```sh
node --test tools/i18n.test.mjs
corepack pnpm build:renderer
cargo check --workspace --locked
cargo test -p codex-state-kit-desktop ui_language::tests --lib --locked
```

Установочный пакет собирается командой `corepack pnpm build`.
