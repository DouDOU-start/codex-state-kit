## 视觉规范

界面采用暖白背景、柔和蓝色主色与少量杏色强调。主题变量集中在 [styles.css](../frontend/src/styles.css)，优先复用变量和现有组件。

| 项目 | 约定 |
| --- | --- |
| 桌面窗口 | 默认与最小尺寸均为 900 × 680，无系统边框、带圆角：Windows 11 用系统原生圆角，macOS 为透明窗口由页面画 10 px 圆角（最大化和全屏时恢复直角），Windows 10 保持直角 |
| 标题栏 | 高度 42 px，展示应用名称、版本、检查更新、GitHub 入口和窗口按钮 |
| 页面结构 | 顶部标签页：概览、使用记录、模型价格、出站网络、Codex 接入、虚拟设备；右侧是账号切换器和接入状态 |
| 提醒与确认 | 统一用主题化的右下角提醒和确认弹窗（`Notifier.tsx`），不用浏览器原生弹窗或页内横幅；状态类提醒随状态出现和消失，关闭后在状态变化前不再弹出 |
| 下拉框 | 统一用 `Select.tsx`，不用原生 `<select>` |
| 字体 | 中文字体排在前面，中英文和数字由同一字体家族渲染；账号 ID 等标识符用 `--font-mono` |
| 窄屏预览 | 740 px 以下改为单列；桌面最小宽度仍为 900 px |
| 状态表达 | 文字配合颜色，保留键盘焦点样式 |
| 文案 | 简短中文，优先说明状态与操作，避免展示内部连接细节 |

开发和浏览器预览显示 `dev`，正式桌面版显示 `v` 加版本号。版本维护见[开发与打包](development.md)。

## 图标维护

[icon.svg](../frontend/public/icon.svg) 是标题栏、浏览器图标及桌面应用图标的统一源文件。修改后在仓库根目录运行：

```sh
corepack pnpm icons
```

该命令更新 `src-tauri/icons/`，并同步旧的 `source.png`。安装包构建前会自动执行，Windows 安装与卸载程序使用生成的 `icon.ico`。

界面功能图标使用现有 Lucide 图标库，不依赖远程字体或图片。

## 验证

执行 `corepack pnpm build:renderer` 检查类型与前端构建，再检查最小窗口尺寸下的布局、长文本、登录等待状态、提醒弹窗和键盘焦点。浏览器预览采用模拟接口；窗口控制、真实登录和代理运行需在桌面应用验证。
